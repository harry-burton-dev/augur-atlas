A kind can carry a military symbol code (APP-6 or MIL-STD-2525, ADR 0070). Admins set it in the studio with **Change…**, which says before saving when a code can't be drawn. The symbol shows on the kind's row and on each of its entities' pages, drawn by milsymbol, which is only downloaded when a symbol is on screen. Kinds without a code keep their icon.
